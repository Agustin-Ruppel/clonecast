# Demo Creator

> Personaje ficticio open-source para probar Clonecast sin usar tu propia identidad.

## Contenido

- `character/` — fotos placeholder (creadas con IA, licencia abierta)
- `brand/` — brand pack genérico
- `scripts/sample-script.json` — script de ejemplo para `clonecast generate --script ./scripts/sample-script.json`

## Para qué sirve

- Probar el pipeline end-to-end sin armar tu Character Pack todavía.
- Tests de integración del repo.
- Demo en docs / videos de onboarding.
